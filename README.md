# Lampa Desktop for Windows

**Неофициальная настольная версия Lampa для Windows 10/11 x64 со встроенным видеопроигрывателем libmpv.**

Оригинальный интерфейс Lampa, современные видеоформаты, аппаратное декодирование, расширенные настройки воспроизведения и интеграция с TorrServer — в одном Windows-приложении.

**Версия:** 1.0.0  
**Платформа:** Windows 10/11 x64  
**Технологии:** Electron · JavaScript · C++ · Node-API · libmpv · FFmpeg  
**Метод разработки:** Vibe Coding

## О проекте

Lampa Desktop — неофициальная адаптация оригинального проекта [Lampa](https://github.com/yumata/lampa-source) для компьютеров под управлением Windows.

Основная цель — сохранить привычный интерфейс и функциональность Lampa, добавив полноценный встроенный видеопроигрыватель без ограничений стандартного HTML5 Video в Chromium.

Вместо браузерного механизма воспроизведения используется **libmpv**, интегрированный в Electron через собственный нативный модуль на C++.

Видео воспроизводится непосредственно в окне Lampa, без запуска VLC, mpv.exe или других внешних проигрывателей.

## Чем отличается от оригинальной Lampa?

| Возможность | Оригинальная веб-Lampa | Lampa Desktop |
|---|---|---|
| Запуск как Windows-приложение | Через браузер или совместимую оболочку | Нативная Desktop-оболочка Electron |
| Встроенный видеодвижок | HTML5 и платформенные механизмы | libmpv + FFmpeg |
| MKV / HEVC / AV1 | Зависит от браузера и платформы | Поддержка через libmpv |
| Аппаратное декодирование | Зависит от браузера | D3D11VA и совместимые GPU-декодеры |
| Dolby Digital / DTS / TrueHD | Ограничено возможностями платформы | Декодирование через FFmpeg/libmpv |
| Многоканальный звук | Зависит от платформы | PCM 5.1/7.1 и поддерживаемый HDMI passthrough |
| Нормализация звука | Web Audio / платформенная реализация | Аудиофильтры libmpv/FFmpeg |
| Настройки качества видео | Стандартные возможности плеера | Расширенные параметры libmpv |
| TorrServer | Подключение к серверу | Интеграция и автоматический запуск |
| Статистика TorrServer | Зависит от интерфейса и версии | Скорость, пиры, кэш |
| Локальный EXE | Не является основным форматом веб-версии | Setup и Portable |

Основное отличие проекта — **замена браузерного видеодвижка на libmpv с максимальным сохранением оригинального интерфейса Lampa**.

## Возможности

### Встроенный видеопроигрыватель

- H.264 / AVC
- H.265 / HEVC, включая Main10
- AV1
- VP8 / VP9
- MPEG-2, MPEG-4
- MKV, MP4, AVI, MOV, WebM, TS, M2TS и другие форматы, поддерживаемые сборкой FFmpeg
- Воспроизведение видео 4K
- Аппаратное декодирование NVIDIA, AMD и Intel через совместимые механизмы Windows
- Программное декодирование при отсутствии аппаратной поддержки

Поддержка HDR, Dolby Vision и отдельных профилей кодеков зависит от видеокарты, драйверов, дисплея и используемой сборки libmpv.

### Звук

- AAC, AC3, E-AC3, DTS, DTS-HD, TrueHD, FLAC, Opus и другие поддерживаемые форматы
- Переключение аудиодорожек в оригинальном интерфейсе Lampa
- Многоканальный PCM
- Настройка HDMI audio passthrough
- Выбор аудиоустройства
- Динамическая нормализация громкости
- Нормализация EBU R128
- Регулировка интенсивности и скорости нормализации

### Настройки libmpv

В оригинальное меню проигрывателя Lampa интегрированы расширенные настройки видеодвижка:

- Масштабирование и соотношение сторон
- Аппаратное декодирование
- Деинтерлейсинг
- HDR и тонмаппинг
- Коррекция изображения
- Интерполяция кадров
- Синхронизация воспроизведения
- Параметры аудиовывода
- Сетевой буфер и кэширование
- Диагностика видеодекодера и потока

Настройки сохраняются между запусками приложения.

### Интеграция TorrServer

Lampa Desktop может автоматически запускать `TorrServer.exe` вместе с приложением.

Реализованы:

- Автоматический запуск локального TorrServer
- Проверка уже работающего экземпляра
- Использование существующего сервера без повторного запуска
- Отображение скорости загрузки
- Отображение количества пиров
- Мониторинг заполнения кэша
- Корректное завершение экземпляра TorrServer, запущенного приложением

TorrServer может использоваться как отдельное приложение или поставляться вместе с Lampa Desktop с соблюдением условий распространения.

### Оригинальный интерфейс Lampa

В отличие от самостоятельных медиапроигрывателей, Lampa Desktop сохраняет привычный интерфейс оригинального проекта:

- Каталог фильмов и сериалов
- Выбор источников воспроизведения
- Работа с торрентами
- Оригинальная панель видеопроигрывателя
- Переключение серий
- Выбор аудиодорожек и субтитров
- Продолжение просмотра с сохранённой позиции
- Совместимость с существующей системой плагинов Lampa в пределах возможностей Desktop-версии

## Установка

В разделе **Releases** доступны два варианта приложения:

**Lampa Desktop Setup** — установочная версия для Windows.

**Lampa Desktop Portable** — версия для запуска без установки.

Для воспроизведения видео не требуется устанавливать отдельные VLC, mpv или FFmpeg: необходимые компоненты включаются в дистрибутив.

Для автоматического запуска внешнего TorrServer используется `TorrServer.exe`, размещённый рядом с исполняемым файлом приложения, либо экземпляр, включённый в соответствующую сборку.

## Vibe Coding — как создавался проект

**Этот проект — вайбкод.**

Lampa Desktop разработана методом *Vibe Coding*: значительная часть кода, архитектурных решений и исправлений создавалась при помощи искусственного интеллекта.

Процесс разработки строился итеративно:

1. Постановка задачи и обсуждение архитектуры с ИИ.
2. Генерация и адаптация исходного кода.
3. Компиляция и запуск на Windows.
4. Проверка реального поведения приложения.
5. Анализ ошибок и доработка кода совместно с ИИ.

В разработке использовались ChatGPT и генерируемый ИИ код.

**Автор проекта не претендует на то, что весь код написан вручную.** Цель эксперимента — показать, что с помощью современных ИИ-инструментов можно адаптировать существующее веб-приложение в полноценную Desktop-версию с нативным видеодвижком.

При этом Vibe Coding не гарантирует отсутствия ошибок. Проект развивается на основе практического тестирования, а исходный код может содержать недочёты, неоптимальные решения и особенности совместимости.

Pull Requests, сообщения об ошибках и предложения по улучшению приветствуются.

## Ограничения

- Проект ориентирован на Windows x64.
- Поддержка отдельных видеокодеков и HDR зависит от оборудования.
- Dolby Vision поддерживается с ограничениями конкретных профилей и сборок.
- HDMI passthrough требует совместимых устройств и драйверов.
- Некоторые плагины Lampa могут быть несовместимы с Desktop-версией.
- Защищённые DRM-потоки не поддерживаются механизмами обхода защиты.
- Приложение может содержать ошибки, связанные с особенностями Electron, Win32 и libmpv.
